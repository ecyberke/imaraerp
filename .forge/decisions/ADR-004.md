# ADR-004 — Database-enforced ledger and audit immutability
Status: accepted 2026-10-02, approved by Lavyd.
## Decision
`BEFORE UPDATE OR DELETE` triggers on `journal_lines`, posted `journal_entries` and `audit_logs` raise an exception; a `DEFERRABLE INITIALLY DEFERRED` constraint trigger checks Σdebit = Σcredit per entry at commit. Reversal stays an INSERT. Test cleanup in the real-concurrency suites uses a role-gated session flag, never a trigger disable in application code.
## Consequences
Reversal-only (v21 §3.9) becomes physically true, not only a coding convention (THR-010). Anonymisation of audit identities (REQ-040) is done through a dedicated SECURITY DEFINER function that only rewrites identity columns, and is itself audited.
