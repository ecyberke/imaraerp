# ADR-008 — Exact integer-cent assertions; retire assertEqualsWithDelta guidance
Status: accepted 2026-10-02, approved by Lavyd · Supersedes: execution_plan.md Cross-Cutting Reminder "using assertEqualsWithDelta for every monetary comparison".
## Decision
Money is integer cents with bcmath (v1.0 implementation). Monetary assertions use exact equality on cents. Any delta tolerance in a financial test is treated as verification tampering.
