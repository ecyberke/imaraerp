# ADR-006 — Merge eTIMS behind a default-off per-tenant flag
Status: proposed.
## Context
PR #20 parses a guessed KRA response shape; nothing has touched the real sandbox. The raw response, retained on failure, may contain the communication key.
## Decision
Add `TenantFeatureFlag` (TASK-100) inside PR #20 before merge; `etims.enabled` and `mpesa.enabled` default false and every adapter call checks it. Scrub secrets from retained raw responses (TASK-137). Enable per tenant only after ACC-003 / ACC-004.
