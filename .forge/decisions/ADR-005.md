# ADR-005 — Token lifecycle and MFA recovery
Status: proposed (ASM-002).
## Decision
Sanctum `expiration` 720 min (30 days with Remember me); 60-min idle timeout for Finance/Admin via `last_used_at`; `sanctum:prune-expired` daily; "sign out everywhere"; TOTP verification rejects reuse of the last accepted timestep (`verifyKeyNewer`); 10 one-time recovery codes, bcrypt-hashed, shown once; Admin MFA reset requires a second Admin and is audited.
