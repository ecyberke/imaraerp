# ADR-003 — PostgreSQL Row-Level Security behind TenantScope
Status: proposed (ASM-009).
## Context
TenantScope is bypassable by raw queries, `withoutGlobalScopes()`, and code running without an authenticated user (queue, scheduler, console). Multi-tenant module: isolation must be impossible to break by construction.
## Decision
Add a `tenant_isolation` RLS policy on every tenant table using `current_setting('app.tenant_id')`, set with `SET LOCAL` at the start of every transaction by TenantContext. A separate `imara_maintenance` role with BYPASSRLS is used only by migrations and the provisioning command. Ship after TASK-135 so every code path already sets TenantContext.
## Consequences
Defense in depth for THR-001/THR-012. Requires the four real-subprocess concurrency tests to set the session variable in their child processes, and PgBouncer in transaction mode (SET LOCAL is pool-safe).
